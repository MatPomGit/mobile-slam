# Milestone 1 — physical-device observations (2026-11-05)

## Evidence and scope

- Device: Samsung SM-S938B (reported by Android), Android 17 / API 37.
- Evidence: two screenshots (main menu; hardware inventory) and an approximately 20.43-second portrait screen recording of **Tryb na żywo**, supplied by the project owner on 2026-11-05.
- App reports version **0.1.0**. The exact installed APK commit SHA was **not established** from this evidence; do not equate this recording with any particular CI build.
- This is a **partial observational record**, not a completed hardware acceptance test. The original media are not committed to this repository.

## Selected reported device capabilities (not measured pipeline performance)

- ABI arm64-v8a, 8 logical processors, approximately 11113 MiB total device RAM.
- Display metrics shown for this application: 1440×2812 px and 600 dpi.
- Camera2 ID 0 (rear-facing), reported sensor orientation 90°, physical sensor size 9.792×7.344 mm, active array 4080×3060 px, focal length 6.300 mm.
- Screen reports a manufacturer's intrinsic calibration vector, but there is **no evidence** that it matches the actual CameraX stream or that distortion/extrinsics are calibrated.
- Battery/thermal readings in the screenshot are point-in-time system values, not a controlled performance measurement.

## Next on-device validation (issue #4)

1. Export **Parametry sprzętowe i diagnostyka → Eksportuj JSON** after at least one camera test and one explicit IMU test; retain the schema/provenance metadata and record APK commit SHA separately.
2. Grant, deny, revoke in Android settings and regrant CAMERA; verify Live camera stops/restarts without a stale permission state or crash.
3. Test overlay registration using an identifiable planar target in four rotations and at two camera/preview aspect ratios; record actual ImageProxy geometry, cropRect and rotationDegrees.
4. Verify full-rate diagnostic accelerometer/gyroscope callbacks, background/foreground lifecycle and camera timestamp source. Do not infer camera–IMU synchronization from numerically similar timestamps.
5. Run a 5–10 minute stability test with diagnostic FPS and thermal observations, noting stalls/ANRs/crashes.
